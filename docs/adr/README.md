# Architecture Decision Records (ADR)

Jede grundlegende, schwer umkehrbare Entscheidung wird hier als kurzes, datiertes Dokument
festgehalten: Kontext, Entscheidung, Alternativen, Konsequenzen. So bleibt über Jahre und
über wechselnde Teams nachvollziehbar, *warum* etwas so ist.
